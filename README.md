## About

One-page responsive campaign website built with Tailwind CSS v4, featuring:
- AI-generated professional headshot
- Font Awesome Pro SVG icons
- Unsplash photography (NB-appropriate)
- UI/UX Pro Max design system (Lexend + Source Sans 3)
- WCAG AAA accessibility
